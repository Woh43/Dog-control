# 延迟执行与 WBC 参考一致性验证（2026-11-15）

本轮没有得到可替换 C04 的新运动配置。已补齐执行边界实现和诊断，并清理失败实验；新路径保持关闭。关节 PD、NMPC Q/R、WBC 权重及保护阈值未调整，没有真机运动。

## 完成的代码

- 带符号的 FF＋PD 窗口预算：WBC 动力学计入名义 PD，总力矩约束覆盖预测 PD 区间，同时保留独立 FF 上限。它依赖假定的加速度上界；接触冲击已使 A=100 rad/s² 假设失效，不能称为严格执行限矩。
- `wbc_nominal_joint_reference`：从同一条生效策略、同一时间直接取名义 q/dq，WBC 和电机共用；同时绕过只平滑 dq 的旧分支。保留接触力反馈。这不保证跨策略更新的 C1 连续性，也不保证独立插值后的 q 导数严格等于 dq。
- `host_total_torque_command`：WBC 直接约束总力矩；发送前合成总请求，记录 raw/sent/scale，发送电机 Kp=Kd=0。交接起点只锁存一次已限幅力矩，短暂 QP 失败保持上一帧总力矩，原故障计数不变。这改变了反馈执行位置，属于实验控制结构。
- 单独提供摆动腿绝对高度恢复及足端球心地面基准；不改变支撑腿约束或全局 `positionErrorGain`。失败的成对关节滤波、phase-aware/lookahead 开关及无计算用途的比例参数已移除。

## 仿真结果

共 26 个独立新世界用例：24 个候选用例未通过，保留配置的两个回归通过。统一使用 20 ms 额外命令延迟、100 Hz IMU、500 Hz 主控、50 Hz NMPC及原验收阈值。

| 配置 | 结果 |
| --- | --- |
| 保留 C04，前后 ±0.5 m/s | 各完成 20 s Trot 和 30 s 停车站立；末 2 s 实速 +0.4876 / −0.4791 m/s，运动平均高度 0.33546 / 0.32972 m |
| 仅摆动高度恢复 G20、球心平面 0.026 m，原内环 | 完整摆腿峰值中位数约 0.090–0.103 m，但前进/后退在 5.474 / 5.216 s 仍触发大腿力矩保护 |
| 窗口预算＋名义 q/dq＋耦合加速度＋高度恢复 | 前进 0.714 s 超过 0.36 m 高度上限；后退 2.216 s 跌破 0.31 m；未通过 |
| 锁存交接的固定总力矩＋上述参考修正 | 初始站立通过；Trot 后约 0.212 s 超过姿态阈值。保护前发送总力矩均未超过 23.7/23.7/45 N·m，非数值级缩放次数为 0，仍未通过运动验收 |

后三组指令目标为 ±1 m/s；提前失败不能视为达到该速度后的稳态测试。不能由这些结果推断硬件只能达到 1 m/s，也不能覆盖用户旧位置控制实测的 3 m/s。

固定总力矩第一版在交接中仍实时计算高增益站立 PD，使该反馈也延迟，站立失败。锁存交接修正后站立通过，但 Trot 仍不稳。此结果区分了“请求幅值受限”和“闭环运动稳定”，不能用前者代替后者。
